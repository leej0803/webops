H.COM MAINTENANCE PROCESS

Project Information

LEGEND

  • BM - Brand Manager
  • DP - Digital Producer
  • PP - Product Planning
  • C - Copywriter
  • PM - Project Manager
  • PA - Production Artist

REQUEST

  • HMA: Smartsheet request submitted by client
  • BM: Confirm details with HMA
  • DP: Review maintenance request, includes
    • Review request and assign a Producer.
    • Determine if the requests fits the maintenance profile and does not align closer to a full project request.
    • If there are addtitonal questions or concerns, further clarification is requested from BM.
    • Create a Basecamp assignment for project communication and tracking of project.

DESIGN/COLLECT

  • DP: Work with Creative(s) to collect assets/documentation for WebOps.
  • DP: Create JIRA ticket, this process includes:
    • For maintenance requests that touch multiple pages, Producer creates an epic with stories to keep request organized.
    • Ensure proper BM and DP resources are attached to the ticket.
    • Ensure that all proper staging/production delivery dates are noted in each ticket.
    • If an update requires alignment with an existing request, all tickets should be linked.
  • DP: Assigns ticket(s) to WebOps or HAEA based on confirming that a page on the site is considered Static (HAEA) or Template (WebOps).

Content Publishing & QA

DEVELOP/CMS

  • WebOps: Review the ticket and work with DP to address questions or concerns
    • Are staging/prod dates feasible?
    • Any missing assets/documentation necessary for request?
    • Are there any conflicting updates? (Ex. MYUs aligning with specific dates that can impact delivery)
    • Enter necessary content for update

TEST/DEPLOY

  • WebOps: Deploy to qa environment through TeamSite
    • Confirm everything in qa environment
    • Deploy to staging environment through TeamSite
    • Confirm everything in staging environment, route links to AM
  • BM: Route links for HMA approval
  • WebOps: Upon approval, deploy to production
    • Confirm everything in production environment
